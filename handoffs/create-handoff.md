# Create and resume a handoff

1. **At session end:** Update `handoffs/current.md` with the project path, files created or changed, checks performed and their results, outstanding questions, and the next task. Link to `docs/verification.md` for detailed evidence. Keep credentials out of the handoff.
2. **At session start:** Read the handoff and `AGENTS.md`, confirm the root, inspect Git status and the named files, and rerun the smallest relevant check to confirm the recorded state before continuing. Record any discrepancy in `docs/verification.md`.
